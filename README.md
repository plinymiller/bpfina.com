# bpfina.com

A one-page hold site: a bold, centered block **88** on a black background, with the site footer credit.

The 88 is a hand-drawn inline SVG in a square, varsity-block style (angular chamfered corners, rectangular counters, a pinched waist). It is original artwork, not a team mark and not a licensed typeface.
