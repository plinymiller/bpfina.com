# bpfina.com

A one-page hold site: the back of a red #88 hockey jersey with the name **FINA**.

The illustration is an original HTML/SVG drawing. It does not use a team crest, shoulder patch, or any league mark. The FINA and 88 lettering are outlines from Saira Black (SIL Open Font License), embedded as SVG paths, so the page loads no web fonts. The SVG is generated by `/workspace/bpfina-work/gen.py` on the shared box.

This repository is prepared locally. Intended GitHub repo: `plinymiller/bpfina.com` (GitHub Pages from `main`, `CNAME` = `bpfina.com`), matching `plinymiller/b-tuff.co`.
